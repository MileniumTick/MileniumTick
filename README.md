## aimux — el proyecto principal

[**aimux**](https://github.com/MileniumTick/aimux) es un multiplexor de providers AI. Una TUI en Go + Bubbletea para centralizar credenciales de Anthropic, OpenAI, Gemini y bindear modelos a Claude Code, Copilot, pi, Codex u OpenCode. Un solo binario, backups automáticos, self-update.

```
┌─────────────────────────────────────────────┐
│  Provider   │  CLI     │  Model             │
├─────────────┼──────────┼────────────────────┤
│  Anthropic  │  pi      │  claude-sonnet-4   │
│  OpenAI     │  codex   │  gpt-4o            │
│  Gemini     │  copilot │  gemini-2.5-pro    │
└─────────────────────────────────────────────┘
```

→ [github.com/MileniumTick/aimux](https://github.com/MileniumTick/aimux)
