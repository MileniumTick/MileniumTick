## Sobre mí

Tico, desarrollador en **Istmo Center**. Trabajo con sistemas que van desde apps de campo con PostGIS hasta herramientas para manejar providers de AI.

Me gusta aprender haciendo — y mantener las cosas simples. Hice [pi-ponytail](https://github.com/MileniumTick/pi-ponytail) justo para eso: código mínimo, stdlib primero, nada que no haga falta.

**Stack con el que trabajo más seguido:**

Backend: Go, Node, Python, Rust
Frontend: React, TypeScript, Astro, Tailwind
Mobile: React Native (Expo)
DB: PostgreSQL, PostGIS, SQLite
Infra: Docker, Kubernetes, CI/CD
AI: routing de providers, multiplexing
TUIs: Bubbletea, Lipgloss
