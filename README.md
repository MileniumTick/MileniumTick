## aimux

[**aimux**](https://github.com/MileniumTick/aimux) es un multiplexor de providers AI en Go + Bubbletea.
Una TUI que centraliza credenciales de Anthropic, OpenAI, Gemini y las bindea
a Claude Code, Copilot, pi, Codex u OpenCode. Un solo binario, backups automáticos.

```
┌──────────────────────────────────────────────┐
│  Provider    │ CLI     │ Model               │
├──────────────┼─────────┼─────────────────────┤
│  Anthropic   │ pi      │ claude-sonnet-4     │
│  OpenAI      │ codex   │ gpt-4o              │
│  Gemini      │ copilot │ gemini-2.5-pro      │
└──────────────────────────────────────────────┘
```

→ [github.com/MileniumTick/aimux](https://github.com/MileniumTick/aimux)
